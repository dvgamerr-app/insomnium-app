# Archive-bound frontend notice corpus proposal

Source-only/offline candidate in the isolated license worktree. Root's actual Bun.lock has 283 deduplicated identities; current native/Spectral collectors do not provide an explicit frontend corpus. This offer implements pure collection/validation and meaningful synthetic guards, without fetching/admitting any real frontend archive or publishing Root resources. Universal37 and all historical proofs remain separate and immutable.

## Concrete source authority

`collector.mjs` has no filesystem, cache, network, process, install or native/application APIs. It takes original lock/package bytes, a closed implementation input table and an explicit Map of supplied archive bytes. It uses existing publisher JSONC parser2.2.1, checks parse errors and duplicate properties, validates current lock format2 and canonical single SHA512 integrity, deduplicates exact identity+integrity+registry rows, and retains all lock keys. Unknown identities, conflicting duplicate integrity and unsupported formats refuse.

Supplied gzip bytes must match the **original lock SHA512** before decompression. Bounded gunzip runs through `node:zlib` inside Bun (no Node executable); selected unchanged native tar checks then inspect data without host extraction: header checksum, package prefix, canonical paths, duplicates, link/unsupported entry types, GNU/PAX names and termination. The copied pure tar function has an exact inverse back to current captured native function; only the bounded-decompression separation changes. No Root parser/default/SDK is modified. Actual package.json name/version and raw manifest/text hashes are derived from the verified archive.

Text discovery collects genuine provided raw LICENSE/NOTICE/COPYING/COPYRIGHT filename candidates and explicitly declared `SEE LICENSE IN <path>` files, preserving original bytes and all nested origins. Source-like filename extensions are excluded. SPDX/deprecated license declarations are recorded as literal metadata, never converted to canonical full texts, interpreted as a license choice, or used to infer copyright or package-wide coverage. Unknown/custom declared syntax or an unsupported authentic archive requires review; it cannot silently fall back to installed files or generic text.

Every row records available, no-candidate-discovered or source-unavailable-in-the-explicit-input-set. Missing supplied source is nonblocking; malformed/integrity/version/source/read/output errors fail. Lock registry strings are retained but an empty/default registry is not guessed to be an independently authenticated publisher URL or Git commit. Root direct dependency/devDependency roles are declarations only, not emitted or target linkage. Transitive/optional/build-only selection is unknown. Both linkage fields and coverage stay unproven/incomplete; completenessBlocksBuild remains false.

## Independent validation and frozen availability

`validateFrontend` first checks exact original independently admitted receipt bytes, then reparses original locked archive bytes and reconstructs every public output. Public blob/receipt/inventory/stamp hashes alone cannot authenticate text. A coherently regenerated public corpus fails against the original private admission; even a coherently rewritten admission still fails when independently held original lock/archive bytes are used. Root's future private admission reader/current marker must supply those trusted original bytes through ordinary canonical source paths; the pure function does not replace that filesystem authority.

Validation selects only sources that the original admitted receipt actually observed. Adding a formerly unavailable archive to another supplied set does not promote or stale that frozen generation; original admitted archive eviction/corruption does refuse. A deliberate later collection admits changed availability as a separate reviewed generation. There is no ambient cache scan or automatic discovery/promotion.

Assets are deterministic canonical receipt/inventory, assembled plain-text notices and content-addressed raw text blobs. No timestamps or absolute workspace/cache paths are embedded. Manifests/archive source bodies are bound by raw hashes, not emitted as full license texts. The validator compares exact output set and bytes; callers must consume validated assets/returned canonical facts rather than treating mutable convenience objects as authority.
