## Freshness policy

The admitted generation freezes cache availability plus exact manifest/VCS/text blobs. Adding a formerly unavailable archive or evicting/changing ambient cache cannot promote or stale the existing snapshot. Explicit recollection creates a new generation. Bundle validates the fixed snapshot and current declared project inputs: collector/policy/packaging scripts, config/ignore, Cargo lock/manifest, project LICENSE and four local patch tree digests. Changes to these inputs, missing/modified declared snapshot/output bytes, malformed provenance, wrong identity/target or read errors fail. Audit docs and unrelated cache are not freshness inputs; incompleteness alone succeeds.

Staging retains old/new generations under ignored artifacts for review; no recursive cleanup is performed. Resource-copy/installed-platform acceptance remains root-owned. Current native990/appbf5e proof predates this collector and is unchanged.
